# Circuit Visual review (CIRCUIT-VISUAL-01 → CIRCUIT-MASTER-FINAL-01)

This folder records the visual acceptance material for the Memory Circuit
visual missions. Nothing in this folder is loaded at runtime.

CIRCUIT-MASTER-FINAL-01 changes on top of the V2 base:

- The Home/transition/intro master-scene WebPs in
  `public/illustrations/worlds/master-scenes/circuit/` are now **derived from
  the V2 kit** by the review script (`deriveMasterSceneAssets`), so every
  context shows the same artifact. `home-vs-game-circuit.png` is the gate.
- Active/complete core crystals keep a deep teal base with restrained
  emission (no white/cyan wash) and smaller glow discs that stay inside the
  bronze ring.
- The idle core crystal and pedestal grew (~13%) so the core reads as the
  heart of the circuit at rest.
- Pad glow strength dropped 0.55 → 0.42 so observe/complete never wash the
  enamel colors (the flame stays coral).
- Top stone gained ramp contrast and stronger bump for mineral variation.
- The legacy V1 PNG kit was archived to
  `docs/archive/memory-circuit/legacy-kit-v1/`.

## Runtime kit

The active visual kit lives in `public/assets/memory-circuit/v2/` and is
generated by:

```powershell
& "C:\Program Files\Blender Foundation\Blender 5.1\blender.exe" --background --python tools\blender\create_memory_circuit_visual_v2.py
```

The seven WebP assets total approximately 444 KB:

- `memory-board.webp`
- `overlay-flame.webp`
- `overlay-wave.webp`
- `overlay-leaf.webp`
- `overlay-sun.webp`
- `overlay-core.webp`
- `overlay-complete.webp`

All files share the same 1280 x 1024 transparent canvas, camera and lighting.
The pad overlays add restrained trail, rim and symbol energy instead of
replacing the idle enamel. This keeps the blue pad blue and every symbol
readable during observation.

## Review sheets

- `board-material-review.png`: board silhouette and material hierarchy.
- `pads-idle-review.png`: the four idle pad identities.
- `pads-active-review.png`: active pad color and symbol preservation.
- `core-states-review.png`: idle, observing and complete core states.
- `trail-states-review.png`: the four core-to-pad routes.
- `full-circuit-idle.png`: composed idle stage reference.
- `full-circuit-observe.png`: composed observation state.
- `full-circuit-player-turn.png`: composed input state.
- `full-circuit-complete.png`: composed completion state.
- `home-vs-game-circuit.png`: current Home derivative beside the game V2.

The full-circuit sheets are deterministic visual-state compositions generated
from the exact runtime assets. They are not substitutes for interaction video.

## Resolved gap

CIRCUIT-VISUAL-01 shipped with the Home master scene still deriving from the
earlier circuit material pass ("parentes", não o mesmo objeto).
CIRCUIT-MASTER-FINAL-01 closed this: the master-scene WebPs are generated from
the V2 kit itself, with no Home code or behavior change. If
`home-vs-game-circuit.png` ever shows two different artifacts again, the
derivation step was skipped after a kit re-render.

## Regenerating the kit, derivatives and sheets

```powershell
& "C:\Program Files\Blender Foundation\Blender 5.1\blender.exe" --background --python tools\blender\create_memory_circuit_visual_v2.py
node tools/assets/create_circuit_visual_review.mjs
```

The node script both derives the master-scene WebPs from the V2 kit and
regenerates every review sheet — always run it after re-rendering the kit.
